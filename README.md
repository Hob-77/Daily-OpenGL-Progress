# OpenGL Learning - Rotating Cube
Learning OpenGL fundamentals by following LearnOpenGL.com, implementing up to a textured rotating cube.

## Overview
This project represents my journey learning modern OpenGL (4.6) by following the LearnOpenGL tutorials. I implemented core graphics programming concepts from scratch, culminating in a textured 3D rotating cube.

## Features Implemented
- **Modern OpenGL Pipeline**: Using OpenGL 4.6 core profile
- **Shader System**: Vertex and fragment shader loading/compilation
- **3D Transformations**: Model, View, Projection matrices using GLM
- **Texture Mapping**: Loading and applying textures with STB Image
- **Mesh Abstraction**: Clean OOP design for rendering

## Technical Components
- `Shader`: Loads, compiles, and manages GLSL shaders
- `Mesh`: Handles VAO/VBO/EBO setup and drawing
- `Texture`: Texture loading and binding
- **Vertex Format**: Position (vec3) + Color (vec3) + TexCoords (vec2)

## Key Concepts Learned
- Graphics pipeline fundamentals
- Shader programming (GLSL)
- 3D math and transformations
- Texture coordinates and mapping
- Vertex attributes and buffers
- Depth testing

## Dependencies
- GLFW (window/context management)
- GLAD (OpenGL loader)
- GLM (mathematics)
- STB Image (texture loading)
